# independent-reasoning · 严谨独立思考

一个用于理论解释、观点讨论、因果分析和方案判断的 Codex 技能。用简洁语言说明关键机制，检验提问中的前提，并依据证据作独立判断。

## 核心行为

- 区分事实、假设与偏好，发现会影响结论的框架问题。
- 解释关键变量、因果关系和成立条件，避免用抽象口号代替解释。
- 检验竞争解释与反例；认可和反对都需要依据。
- 先给结论，再给必要理由，保留影响判断的不确定性。
- 尊重用户的任务范围；翻译、格式转换和机械操作不强加分析。

## 安装与使用

将本仓库中的 `SKILL.md` 和 `agents` 目录放入个人技能目录的 `independent-reasoning` 文件夹，例如 `~/.codex/skills/independent-reasoning/`。

在聊天中调用：

```text
使用 $independent-reasoning 回答：检验我的前提，独立判断，并用简洁语言解释关键机制和成立条件。
```

显式启用后，未指定范围时用于当前聊天后续需要分析判断的回答。可要求暂停、恢复或仅用于本轮；安装本技能不会修改全局默认指令。
